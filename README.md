# Tyrans → MakePlayingCards autofill

Automatically fill a [MakePlayingCards](https://www.makeplayingcards.com/) project with the cards
generated by the Tyrans card generator.

This repository is a trimmed-down fork of the desktop tool from
[chilli-axe/mpc-autofill](https://github.com/chilli-axe/mpc-autofill), with:

- **`export_svg_deck_to_mpc_order.py`** (new): converts the Tyrans CSV and generated card images
  into MPC Autofill order XML files that point at the images on disk.
- **`src/driver.py`** (patched): the project SSID is now also read when `ssid` is not the first
  query parameter of the MPC editor URL (`...?foo=bar&ssid=...`), which otherwise made the tool
  loop on *"The SSID of the project cannot be determined"*.

Everything else (`autofill.py`, `src/`) is the upstream desktop tool, unchanged.

## Setup

Requires Python 3.13+ and Chrome (or another supported browser).

```bash
pip install -r requirements.txt
```

## Usage

### 1. Build the order XML from the Tyrans output

```bash
python export_svg_deck_to_mpc_order.py \
  --csv "path/to/Tyrans/Updated_Cards.csv" \
  --images-dir "path/to/Tyrans/output/.pdf_temp" \
  --back-image "path/to/Tyrans/back.png" \
  --output mpc_order.xml
```

| Option          | Description                                                                 |
|-----------------|-----------------------------------------------------------------------------|
| `--csv`         | CSV used by the Tyrans generator. Card name from `nom`/`name`/`title`, copy count from `Impression` (defaults to 1). |
| `--images-dir`  | Folder with the generated images, named `NNN_<card_name>.png` (also `.svg`, `.jpg`, `.jpeg`, `.webp`), where `NNN` is the 1-based CSV row index. |
| `--back-image`  | Shared card back image (required).                                          |
| `--output`      | Destination XML (default `mpc_order.xml`).                                  |
| `--stock`       | Card stock (default `(S30) Standard Smooth`).                               |
| `--foil`        | Mark the order as foil.                                                     |

MPC projects are limited to 612 cards. Larger decks are split automatically into
`mpc_order_001.xml`, `mpc_order_002.xml`, … (612 cards each, the last one holding the rest).

### 2. Fill the MPC project

Run the autofill tool from the folder containing the XML file(s):

```bash
PYTHONUTF8=1 python autofill.py --directory . --browser chrome --site MakePlayingCards
```

If several XML files are found you will be asked which ones to process. Run `python autofill.py --help`
for all options (auto-save, image post-processing / max DPI, PDF export, ...).

`PYTHONUTF8=1` avoids encoding errors with accented card names on Windows
(in PowerShell: `$env:PYTHONUTF8 = 1` before running the command).

## Inspecting the XML

The XML is not a visual preview. Open it in an editor or a browser to check the slot assignments,
or use the Tyrans generator's PDF output / the generated images for a visual check.
